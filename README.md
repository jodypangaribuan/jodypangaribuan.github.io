# 🚀 Jody's Portfolio

Hey there! 👋 Welcome to my digital playground where I showcase the cool stuff I've been building.

## 🎯 What's This All About?

This is my personal portfolio website - think of it as my digital business card, but way cooler! I built this to show off my projects, skills, and maybe convince someone that I'm not just another developer who talks to computers all day (though I totally do that too 😄).

## 🛠️ Tech Stack

- **Frontend**: React.js with some fancy animations
- **Styling**: Tailwind CSS (because who has time to write custom CSS?)
- **Icons**: React Icons (the good stuff)
- **Animations**: Framer Motion (smooth like butter 🧈)

## 🎨 Features

- **Responsive Design**: Works on everything from a smartwatch to a smart fridge
- **Dark Theme**: Because light themes are so 2010
- **Smooth Animations**: Because static websites are boring
- **Project Showcase**: Where I show off my coding adventures
- **Contact Form**: So you can tell me how awesome my code is (or not 😅)

## 🚀 Getting Started

Want to run this locally? Here's the magic:

```bash
# Clone this bad boy
git clone https://github.com/jodypangaribuan/jodypangaribuan.github.io.git

# Jump into the directory
cd jodypangaribuan.github.io

# Install the goodies
npm install

# Start the party
npm start
```
